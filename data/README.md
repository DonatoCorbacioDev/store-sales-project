# Dataset

This project uses the Kaggle **Store Sales Time Series Forecasting** dataset.

Dataset source:

https://www.kaggle.com/competitions/store-sales-time-series-forecasting

Main files used in this project:

* `train.csv`
* `test.csv`

Additional datasets available for future extensions:

* `oil.csv`
* `transactions.csv`
* `holidays_events.csv`
* `stores.csv`

The raw dataset files are not included in this repository because of their size.

After downloading the dataset from Kaggle, place the CSV files inside:

```text
data/
```
